## A normal shift

```text
Morning   Check departures out, take payment, issue invoices
          Release rooms to housekeeping
Midday    Answer enquiries, take bookings, chase deposits
Afternoon Check arrivals in from 14:00
Evening   Post late charges, hand over the cash drawer
Night     Run the night audit
```
