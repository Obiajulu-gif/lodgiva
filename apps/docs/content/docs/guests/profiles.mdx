## What a profile holds

| Field | Notes |
| --- | --- |
| Name | As it should appear on the invoice |
| Phone | The most reliable way to find a Nigerian guest |
| Email | Optional; used for confirmations |
| Nationality | Defaults to Nigerian on Nigerian properties |
| ID type and number | Passport, driver's licence, **NIN**, voter's card |
| Address | Needed on invoices for company guests |
| Notes | Preferences and anything staff should know |

## Finding a guest

Search by name, phone or email from **Guests**. Searching before creating is
the single habit that keeps the list clean.

## Duplicates

Duplicates happen: "Chinedu Okafor" and "C. Okafor" with the same phone
number. Lodgiva can **merge** two profiles, moving stays and history onto the
one you keep.

<Warning>
Merging cannot be undone. Check both profiles are really the same person,
using the phone number, before you merge.
</Warning>

## Company guests

For a company booking, put the company's name and address on the profile so
it lands on the invoice. Their TIN belongs there too, if they need it on the
invoice for their own records.
