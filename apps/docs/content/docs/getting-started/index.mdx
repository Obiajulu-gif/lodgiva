## Before you start

You need a Lodgiva installation and a staff account.

- **No installation yet?** See [Installing Lodgiva](/docs/install). One command
  puts it on an Ubuntu server, with HTTPS.
- **Someone else installed it?** Ask them for your sign-in address and
  account. Staff accounts are created by an administrator, as described in
  [Staff and roles](/docs/administration/staff-and-roles).

<Note>
The first account on a new installation is called **`Administrator`**, not an
email address. Signing in with an email address that has not been added yet
returns "Wrong email, username, or password", because no such user exists.
</Note>
