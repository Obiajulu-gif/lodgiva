## The money rules Lodgiva enforces

These are not suggestions; the system refuses to break them.

| Rule | Why |
| --- | --- |
| A guest with a balance cannot be checked out | Stops unpaid departures |
| A bill with a balance cannot be closed into an invoice | An invoice states the stay was paid |
| A non-cash payment must carry a reference | Untraceable money is missing money |
| The same reference cannot be used twice on one bill | Stops a transfer being counted twice |
| A charge is never deleted, only reversed | The history stays auditable |
