## What gets installed

One command produces a working hotel system behind HTTPS:

| Address | What is there |
| --- | --- |
| `/` | The Lodgiva landing page |
| `/lodgiva` | The PMS staff sign-in |
| `/book` | The guest booking page |

It also starts Frappe's scheduler, which is what runs the night audit. Without
it, room charges silently stop posting.
